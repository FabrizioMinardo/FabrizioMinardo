Sobre mí

Soy Analista IT, recibido de Analista de Sistemas, con experiencia en distintas áreas, principalmente en el rubro de salud.

Me enfoco en entender qué necesita el negocio, cómo afecta un problema a quienes participan del proceso y buscar soluciones funcionales y eficientes.

Mi experiencia combina análisis funcional, análisis de procesos, automatización, datos y desarrollo de sistemas, actuando como vínculo entre las necesidades del negocio, los usuarios y las soluciones digitales.

Proyectos destacados

Get Waiter – Sistema de atención y gestión operativa

Evolución de un sistema web de atención para restaurantes, orientado a centralizar la operación, automatizar tareas y generar información para analizar el uso del sistema.

  • Función: Gestión de pedidos, asistencia, cuentas, métricas y notificaciones.
  • Tecnologías: Google Apps Script, JavaScript, Google Sheets, Telegram Bot API.
  • Rol: Análisis, diseño, desarrollo, implementación y evolución.
  • Enfoque: Automatización de procesos, seguimiento de interacciones y análisis de utilización.

UGAB – Sistema de atención para restaurante

Sistema web de atención mediante código QR desarrollado para facilitar la comunicación entre clientes y personal y centralizar las solicitudes realizadas desde las mesas.

  • Función: Acceso al menú, solicitud de asistencia y pedido de cuenta desde la mesa.
  • Tecnologías: HTML, CSS, JavaScript, Telegram Bot API.
  • Rol: Análisis de necesidades, desarrollo e implementación.
  • Enfoque: Digitalización del proceso de atención y mejora de la comunicación entre clientes y personal.

TuFut – Sistema de gestión deportiva

Sistema de gestión para clubes deportivos orientado a centralizar reservas, pagos y usuarios, mejorando el control de la información y la trazabilidad de la operación.

  • Tecnologías: PHP, MySQL, Docker.
  • Rol: Desarrollo backend y diseño de base de datos.
  • Enfoque: Gestión de información, automatización y organización de procesos administrativos.
